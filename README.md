# YouTube Chrome Extension

An AI-powered Chrome Extension and backend service for YouTube video interaction and question answering.

## Setup

1. **Create and activate virtual environment:**
   ```bash
   uv venv Yt-ChatBot
   .\Yt-ChatBot\Scripts\activate
   ```

2. **Install dependencies:**
   ```bash
   uv pip install -r requierments.txt
   ```

3. **Configure Environment:**
   - Create a `.env` file and populate required API keys (e.g., Google GenAI, Groq).
