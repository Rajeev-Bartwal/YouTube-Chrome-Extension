YouTube AI Extension Local Tester

Test the Chrome extension popup directly in your browser. This simulator runs the exact same popup.html and connects to your local FastAPI RAG backend.

Step 1: Start Backend Server

Make sure your Python virtual environment and server are running:

python server.py

Step 2: Load Unpacked into Chrome

To install directly in Google Chrome / Brave / Edge:

  1. Open chrome://extensions
  2. Turn ON Developer Mode (top right)
  3. Click Load unpacked
  4. Select the extension folder

Step 3: Test on YouTube

Open any YouTube video, click the extension icon in the toolbar, and start chatting!
